# Royal Touch Events

Premium event management and planning solutions based in Nairobi, Kenya. We plan. You celebrate. We make it memorable.

## 🌐 Overview
**Royal Touch Events** is a high-performance web platform designed to streamline event booking, inquiries, and portfolio showcasing. This project provides a modern, responsive, and elegant digital experience for clients seeking professional event services.

## 🚀 Key Features
*   **Modern Booking System:** Seamless event inquiry and quotation request forms.
*   **Elegant Portfolio:** High-quality gallery showcasing weddings, corporate events, and more.
*   **Fully Responsive:** Optimized for mobile, tablet, and desktop viewing.
*   **Interactive Design:** Smooth animations and a premium event-themed UI.
*   **Direct Communication:** Integrated WhatsApp support and one-click contact options.

## 🛠 Tech Stack
*   **Framework:** React / Vite / TanStack Start
*   **Styling:** Tailwind CSS / Framer Motion
*   **Deployment:** Vercel
*   **Runtime:** Bun

## 📖 Site Structure
1.  **Home:** Hero section, services summary, and testimonials.
2.  **About Us:** Company mission, vision, and team achievements.
3.  **Services:** Extensive list of event offerings (Weddings, Concerts, Corporate, etc.).
4.  **Portfolio:** Categorized high-quality event media.
5.  **Booking:** Inquiry form with date and budget selection.
6.  **Contact:** WhatsApp integration, maps, and direct contact details.
